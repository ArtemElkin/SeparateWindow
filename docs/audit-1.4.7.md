# Аудит Separate Window 1.4.7

19 ноября 2026. Проверены рабочий код расширения, разрешения, хранение данных, русская и английская локализации и состав архива для Chrome Web Store.

| Область | Исправление и проверка |
| --- | --- |
| Открытие и возврат окна | Операции для одной вкладки выполняются по очереди. Закрытие сразу после открытия больше не обгоняет запись о переносе. При ошибке возврата страница остаётся изолированной в прежнем окне. При ошибке сохранения настроек успешно открытое окно не закрывается. Проверки отказов в `tests/lifecycle.js`, обычный и ручной перенос в `tests/smoke.py`. |
| Восстановление и навигация | При возврате восстанавливается закреплённая вкладка. Временная пустая вкладка сохраняется, если пользователь уже начал её использовать. Переход на другой путь не применяет селектор исходной страницы. При закрытии отдельного окна восстанавливается последний веб-адрес. |
| Изменения страницы | Блок остаётся видимым после подмены или переноса в другой контейнер. Если он исчез окончательно, возвращаются исходная страница и кнопка возврата. `tests/dashboard.py` проверяет разметку, реальные пиксели и клики. |
| Плееры и PiP | Возврат во вкладку закрывает созданное расширением PiP, в том числе во вложенном iframe. Для предпросмотра введён предел ожидания кадра. При таймауте захват останавливается и кнопкой можно воспользоваться снова. `tests/pip.py --chrome --headed` проверяет плеер, вложенные фреймы, панель YouTube и живой предпросмотр. |
| Данные и снимки | Инкогнито больше не пишет адрес и выбор в постоянные настройки. Возврат использует временное состояние сеанса. Расширение проверяет активную вкладку до и после снимка и отклоняет его при несовпадении. |
| Интерфейс и выпуск | Горячая клавиша и контекстное меню используют общее действие. Меню отображает сочетание, заданное в Chrome. Проверены RU/EN, ссылки обратной связи, иконки и запуск из распакованного ZIP. |

Проверки воспроизводятся командами `node tests/lifecycle.js`, `python tests/smoke.py`, `python tests/dashboard.py`, `python tests/languages.py`, `python tests/popup.py`, `python tests/pip.py --chrome --headed`, `python tools/package.py` и `python tools/verify_release.py`.

Проверки браузера выполнялись на Windows в отдельных профилях. Отказы API и запись в инкогнито проверены также в тесте worker с имитацией ответов Chrome. Частные дашборды, подписочные сервисы под аккаунтом и другие ОС отдельно не проверялись. Для публичных плееров сохраняется [отчёт предыдущей проверки](player-checks.md).
